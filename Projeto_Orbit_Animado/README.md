# Projeto Orbit - Landing Page Animada

Projeto educacional de landing page com **HTML, CSS e JavaScript**, usando o GSAP para criar animações sincronizadas com o scroll.

A versão foi redesenhada para substituir o produto de marca por um **drone espacial original**, mantendo a mesma ideia didática: um elemento principal fica em movimento na página, muda de posição, muda de escala e acompanha a rolagem.

## O que os alunos vão praticar

- Estruturação com HTML semântico.
- Estilização avançada com CSS.
- Responsividade com `@media`.
- Camadas, posicionamento absoluto e `z-index`.
- Animação com GSAP e ScrollTrigger.
- Organização de arquivos de um projeto web.

## Como executar

1. Abra a pasta do projeto no VS Code.
2. Clique com o botão direito no `index.html`.
3. Escolha **Open with Live Server**.
4. Role a página para ver o drone se movimentando.

Também é possível abrir o arquivo `index.html` diretamente no navegador, mas o Live Server costuma evitar problemas com caminhos de arquivos.

## Arquivos principais

- `index.html`: conteúdo e estrutura.
- `style.css`: visual, responsividade e efeitos.
- `script.js`: animações com GSAP.
- `Assets/`: imagens SVG originais do projeto.

## Desafio para a turma

Cada aluno pode trocar o drone por outro elemento: foguete, robô, mascote, produto fictício, bola, personagem ou objeto criado por eles. Depois, podem alterar o movimento no `script.js`.
