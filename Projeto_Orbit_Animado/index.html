Projeto prático de animação com scroll

ORBIT

Uma landing page educativa com elementos que se movimentam conforme o usuário rola a página.

Nosso projeto é de um:

drone espacial

O objetivo continua o mesmo: usar HTML, CSS e JavaScript para criar uma página visual, com um objeto principal que muda de posição, escala e rotação durante o scroll.

A troca remove a dependência de uma marca comercial e deixa o projeto mais livre para os alunos personalizarem com qualquer tema: robô, foguete, personagem, produto fictício ou mascote da turma.

Desafio para a turma

Personalize o objeto animado

  1. Troque o SVG do drone por outro elemento.
  2. Altere cores e tipografia no CSS.
  3. Mude os valores de posição no JavaScript.
  4. Teste o resultado rolando a página no navegador.
